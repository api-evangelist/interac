# Interac

> Interac Corp. is Canada's domestic payments and digital verification network — shared national payment infrastructure owned by a consortium of Canadian financial institutions. It operates Interac Debit, Interac e-Transfer, and Interac verification / digital identity services. Its most openly documented public API is the Interac Hub Verification Service, an OAuth 2.0 / OpenID Connect identity-verification API (Authorization Code Grant with Pushed Authorization Requests).

## APIs
- [Interac Hub Verification API](https://documents.hub-verify.innovation.interac.ca/docs/overview): OAuth2/OIDC identity verification via financial-institution auth (IVS) and government-ID + selfie (IDVS).

## Contract
- [OpenID Connect discovery](https://gateway-portal.hub-verify.innovation.interac.ca/.well-known/openid-configuration): live issuer metadata (authorization, PAR, token, userinfo, JWKS endpoints). The single public machine-readable contract — no OpenAPI is published.
- [JWKS](https://gateway-portal.hub-verify.innovation.interac.ca/.well-known/jwks.json): RS256 id_token signing keys.
